# Архив WhatsApp

Локальное приложение для своих чатов WhatsApp из бэкапа iPhone. В одном окне три шага:

1. **Выгрузка:** одна кнопка забирает из бэкапа все чаты и медиа.
2. **Расшифровка:** голосовые и видео превращаются в текст, на видеокарте или через API.
3. **RAG:** поиск и вопросы по всей истории вместе с расшифровками, локально или через API.

[English version](README.md)

Проект основан на [WhatsApp-Chat-Exporter](https://github.com/KnugiHK/WhatsApp-Chat-Exporter) (автор Knugi, лицензия MIT). Его инструкция и все возможности командной строки описаны в [README.upstream.md](README.upstream.md). Команда `wtsexporter` из исходного проекта тоже входит в пакет.

## Запуск

Нужен Python 3.10–3.12. Для расшифровки через API также нужен `ffmpeg`.

1. Сделайте бэкап iPhone на компьютер через Apple Devices, iTunes или Finder. Шифрование должно быть выключено.
2. Создайте виртуальное окружение:

```bash
python -m venv .venv
```

3. Установите приложение (на macOS и Linux вместо `.venv\Scripts\` пишите `.venv/bin/`):

```bash
.venv\Scripts\pip install -e ".[app]"
```

4. Запустите его:

```bash
.venv\Scripts\whatsapp-archive
```

Откроется страница `http://127.0.0.1:8765`.

Для локальной работы нужны:
- видеокарта NVIDIA для быстрой расшифровки, иначе она пойдёт на процессоре и намного медленнее;
- [Ollama](https://ollama.com) с моделью `bge-m3` для индекса;
- любая модель Ollama для ответов на вопросы. Без неё работает кнопка «Только найти».

Для работы через API задайте переменную окружения `OPENAI_API_KEY` и перезапустите приложение. Подойдёт любой сервис, совместимый с API OpenAI: адрес и названия моделей меняются в настройках. Ключ читается только из окружения и не сохраняется на диск.

## Остановка и продолжение

Любой шаг можно прервать кнопкой «Остановить» или «Выключить приложение», закрытием окна и даже отключением питания. Сделанное не теряется, а кнопка сама сменится на «Продолжить».

| Шаг | Что сохраняется | Что будет сделано ещё раз |
|---|---|---|
| Выгрузка | Каждый из 4 шагов, готовые файлы и страницы чатов | Шаг чтения сообщений или загрузки в архив, если прервали именно его |
| Расшифровка | Каждый готовый файл | Только файл, который обрабатывался в момент остановки |
| Индекс | Каждая пачка из 32 фрагментов | Только текущая пачка. Сборка фрагментов выполняется заново, готовые векторы не теряются |

Если выбрать другой или более новый бэкап, выгрузка начнётся заново, но готовые расшифровки сохранятся.

## Без установки: `tools/export_whatsapp`

[`tools/export_whatsapp/export_whatsapp.py`](tools/export_whatsapp/) — один файл Python без зависимостей. Он выгружает чаты в HTML, текст и JSONL, без приложения, расшифровки и поиска. Используйте его, если чаты нужны только в виде файлов.

```bash
python tools/export_whatsapp/export_whatsapp.py
```

## Приватность

- Все данные лежат в папке `data/`, она исключена из git. Не добавляйте её в общие облачные папки: там личные сообщения других людей.
- Приложение слушает только `127.0.0.1` и отклоняет запросы с других сайтов.
- В локальном режиме данные не покидают компьютер. В режиме API приложение показывает, что и куда уйдёт, и отправляет только после подтверждения.
- С включёнными жёсткими ссылками файлы в `data/` это те же файлы, что и в бэкапе. Не редактируйте их. Удалять безопасно.
- Выгружайте только те бэкапы, к которым у вас есть законный доступ.

## Настройки через переменные окружения

| Переменная | Что делает |
|---|---|
| `WA_ARCHIVE_DATA` | Папка данных. По умолчанию `./data` |
| `WA_MEDIA_FALLBACK` | Необязательная вторая копия медиа из бэкапа, например на NAS. Если файла нет в `data/`, приложение читает его оттуда. Несколько папок разделяйте `;` |
| `OPENAI_API_KEY` | Ключ для режима API. Имя переменной меняется в настройках |

## Отличия от исходного проекта

- Приложение с интерфейсом, расшифровкой и RAG (пакет `whatsapp_archive`).
- Флаг `--link-media`: жёсткие ссылки вместо копирования медиа.
- Флаг `--resume-html` и запись страниц через временный файл: прерванная выгрузка не оставляет обрезанных страниц.
- Ответы на сообщения с id любой длины, а не только из 20 символов.
- Имена участников групп, известных только по внутреннему `@lid`.
- Группы с одинаковыми названиями больше не затирают страницы друг друга.

## Ограничения

- Зашифрованные бэкапы и WhatsApp Business в приложении пока не поддерживаются. Команда `wtsexporter` их умеет.
- Реакции не выгружаются.
- Расшифровка через API принимает файлы до 25 МБ после сжатия, это примерно 100 минут записи.
- Режимы API проверены тестами на подставном сервисе, а не на настоящем.

## Тесты

```bash
.venv\Scripts\python -m pytest
```

Тесты используют только выдуманные данные и не обращаются к внешним сервисам. На Windows запускайте их с переменной окружения `PYTHONUTF8=1` и с папкой `.venv\Scripts` в `PATH`.
